# FE-006: Окно сессионного лидерборда

Визуализатор читает обновляемый сервером JSON-файл по `DATS_LEADERBOARD_PATH` (по умолчанию корневой `leaderboard.json`). Отдельное немодальное окно открывается кнопкой в HUD или клавишей `L`; в таблице отображаются ранг, команда, текущие очки/золото, собранное золото, погибшие ковры и дистанция. Пустое/временно недоступное содержимое не влияет на рендер мира и сетевое управление.

## Критерии приемки

- Окно можно открыть/закрыть кнопкой и `L`.
- Данные обновляются из атомарно заменяемого файла без перезапуска визуализатора.
- Сырые auth tokens не отображаются и не читаются визуализатором из файла.
