# DR-001: Наблюдение и интерактивная визуализация игрового мира

## 1. Бизнес-контекст

**Проблема / возможность:** оператору нужно видеть живое состояние крупной арены и разбирать движение собственного флота, противников, монет и аномалий. Текущая Python-реализация не обеспечивает желаемую плавность при полной сцене.

**Цель:** отдельный быстрый Rust-клиент показывает мир по официальному токенизированному API, сохраняет понятные инструменты наблюдения и дает диагностику прибыльности кандидатных курсов.

**Пользователи:** оператор выбирает ковер, следит за ним, включает веер и при необходимости отдельно переключает ручное управление.

**Метрики:** целевой рендер — 60 FPS на типовой сцене; сетевой опрос — около одного раза на серверный тик; пропуск кадра не должен блокировать API worker.

## 2. Сценарии использования

### Основной сценарий

1. Оператор запускает приложение с URL и обязательным `--token`.
2. Клиент вызывает единственный внешний endpoint и принимает Desert snapshot.
3. Сцена плавно отображает состояния сущностей, HUD и траектории; камера управляется мышью и клавиатурой.
4. Оператор отдельно включает веер или ручное управление выбранным ковром.

### Исключительные ситуации

| Условие | Реакция |
|---|---|
| Сервер недоступен | Сохранить последний кадр, показать stale/disconnected состояние и продолжать повторные запросы с backoff. |
| Ответ не соответствует контракту | Не заменять последний валидный snapshot; показать ошибку в HUD/log. |
| Нет валидного токена | Не запускать сеть; завершить запуск с понятной ошибкой аргументов. |

## 3. Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-01 | Показывать карту и все сущности из Desert API с правильными координатами и масштабом. | Must |
| FR-02 | Отличать свои ковры, вражеские ковры, bounties, притягивающие и отталкивающие аномалии. | Must |
| FR-03 | Показывать три вектора транспорта `velocity`, `selfAcceleration`, `anomalyAcceleration`. | Must |
| FR-04 | Позволять наблюдать выбранный ковер без включения ручного режима. | Must |
| FR-05 | Оценивать курсы по фактическим bounty points / времени до последней bounty и показывать лучшие варианты. | Should |
| FR-06 | Плавно интерполировать визуальные позиции, не меняя серверную физику и данные команд. | Should |
| FR-07 | Позволять включить карту результирующего векторного поля аномалий на пространственной сетке; направление и относительная сила в узле соответствуют суммарному ускорению аномалий в этой точке. | Should |

## 4. Нефункциональные требования

| ID | Требование | Значение |
|---|---|---|
| NFR-01 | Частота кадра | Цель 60 FPS; тяжелый расчет не блокирует event loop UI. |
| NFR-02 | Изоляция | Crate и бинарник не связываются с серверным executable. |
| NFR-03 | API | Только контракт корневого DR-009: `POST /play/magcarp/player/move`. |
| NFR-04 | Устойчивость | Сетевые ошибки не закрывают окно и не очищают последний валидный кадр. |

## 5. Бизнес-правила

1. Выбор ковра — только наблюдение; ручное управление включается отдельным действием.
2. Синие аномалии отталкивают, красные притягивают; ядро непрозрачно залито цветом типа, зона действия полупрозрачна.
3. Смертельный прогноз заканчивается в точке первого столкновения и имеет маркер-крест.
4. `score_rate` использует только фактически пересеченные монеты, не near-miss потенциал.
5. Векторное поле аномалий суммирует вклады всех аномалий в каждом узле по физической формуле прогноза; притягивающие и отталкивающие вклады могут взаимно компенсироваться.

## 6. Логическая модель

Сущности `DesertSnapshot`, `Transport`, `Enemy`, `Anomaly`, `Bounty` и `TrajectoryForecast` являются клиентскими read models. HTTP worker публикует неизменяемые snapshots в UI; UI вычисляет экранную проекцию и интерполяцию.

## 7. API-контракт

API задается общим [`DR-009`](../../../domain/DR-009-legacy-world-contract.md); визуализатор не создает собственных `/api/*` endpoint.

## 8. Критерии приёмки

- [ ] AC-01: полный кадр отображается без заметных рывков при работающем сетевом опросе.
- [ ] AC-02: корректно отображаются карта, все bounty, аномалии, свои и вражеские транспорты.
- [ ] AC-03: на выбранном транспорте отдельно различаются три физических вектора.
- [ ] AC-04: отсутствие сервера/плохой ответ не завершает графическое приложение.
- [ ] AC-05: окно можно запустить только с обязательным непустым `--token`.
- [ ] AC-06: при включении карты поля сеточные стрелки показывают результирующее направление и относительную силу anomaly acceleration; при выключении слой отсутствует.

## 9. Вопросы и допущения

**Допущение:** визуальная интерполяция может сглаживать позиции между ответами, но все score и команды считаются только по состоянию ответа сервера.

## 10. Зависимости

Корневой Desert API, правила мира из `docs/mechanics.md`, Rust toolchain и нативный графический backend.
