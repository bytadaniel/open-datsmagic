# FE-007: Окно информации об активном мире

Визуализатор раз в секунду читает runtime-файл `apps/arena-hub/data/current_world.json` (путь по умолчанию; настройка `DATS_WORLD_STATUS_PATH`). Кнопка «О мире» показывает ID и порядковый номер профиля из `assets/worlds.json`, название, описание, геометрию арены, фиксированный тик 200 мс и параметры ковров, монет и аномалий.

Файл является описанием текущего сервера, а не конфигурацией для редактирования. Профиль читается из JSON, а динамическая расстановка сущностей не обязана быть воспроизводимой между запусками. Если runtime-файл отсутствует, окно показывает путь и сообщение о недоступности; основная визуализация продолжает работать.

## Критерии приемки

- Кнопка «О мире» открывает и закрывает окно.
- ID, название и числовые параметры совпадают с опубликованным сервером профилем; seed нигде не требуется.
- Tick отображается как фиксированные 200 мс.
- Отсутствие runtime-файла `current_world.json` не ломает игровой HUD и сетевой polling.
