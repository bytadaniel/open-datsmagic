# FE-006: Окно лидерборда Hub

Визуализатор получает leaderboard через Hub API `GET /api/leaderboard?scope=all`; локальный `leaderboard.json` не читается. Адрес Hub задаётся `--hub-url`, по умолчанию строится из host/scheme `--url` с портом 8090. Отдельное немодальное окно открывается кнопкой в HUD или клавишей `L`; в таблице отображаются ранг, имя команды, число попыток, метрики лучшей попытки (`top`) и суммарные метрики (`total`). Строка своей команды находится по `team_id` — FNV-1a fingerprint текущего токена — и помечается как «Ваша команда». Пользовательский псевдоним остаётся локальной настройкой визуализатора. GET API не требует отправлять токен; пустой/временно недоступный Hub не влияет на рендер мира и управление.

## Критерии приемки

- Окно можно открыть/закрыть кнопкой и `L`.
- Данные периодически обновляются по Hub API без перезапуска визуализатора.
- Визуализатор не читает локальный файл leaderboard и не отправляет auth token в Hub GET-запросе.
- Своя команда определяется по стабильному `team_id` из ответа API и визуально отделяется от остальных.
- Локальный псевдоним команды редактируется и сохраняется между запусками.
