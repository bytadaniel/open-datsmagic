# FE-001: Конфигурация и сетевой запуск Java-игрока

## 1. Контекст и бизнес-цель

Сделать сохранённый Java-пакет запускаемым против активного StadMagic API без редактирования исходника и без передачи токена в аргументах командной строки. Поведенческий алгоритм игрока остаётся прежним.

## 2. Архитектурное решение

- `Main` выбирает режим через `DATS_GAME_MODE`: `fixture` (по умолчанию) или `api`.
- В режиме `api` требуются `DATS_PLAYER_TOKEN` и `DATS_GAME_API_URL`; токен не имеет значения по умолчанию и не выводится в лог.
- `RequestManager` строит POST с `Content-Type: application/json`, `X-Auth-Token` и JSON телом.
- Первый пакет — `{"transports":[]}`; после получения snapshot клиент выполняет существующий `BruteForce.solve` и отправляет сериализованный `PlayerAction`.
- Минимальная длительность цикла — около 350 мс плюс время обработки; частота ниже установленного лимита 5 HTTP-запросов/с/токен.
- Fixture-файл читается только в офлайн-режиме. В API-режиме он не загружается.
- Визуализация включена по умолчанию и обновляется снимками API; `DATS_SHOW_VISUALIZATION=false` отключает окно. `DATS_PLAY_SOUND` по умолчанию `false`.
- `scripts/run_java_sas4eka.sh` компилирует Java-файлы с локальными Jackson JAR и запускает их; `DATS_GAME_MODE=api` включает сетевой режим.

## 3. Схема базы данных (Prisma)

Изменений базы данных нет.

## 4. Алгоритмы и вспомогательные функции

Алгоритм `BruteForce.solve`, физические допущения и оценки не меняются. Изменения касаются выбора режима, конфигурации клиента и корректности первого запроса/HTTP-ошибок.

## 5. API-контракты и DTO

### Изменённые эндпоинты

Новых endpoint нет. Используется единственный игровой `POST /play/magcarp/player/move`.

### Настройки запуска

| Переменная | Обязательность | Значение |
|---|---|---|
| `DATS_GAME_MODE` | Нет | `fixture` по умолчанию; `api` для сервера |
| `DATS_PLAYER_TOKEN` | В режиме `api` | Выданный Hub токен, отправляется только в `X-Auth-Token` |
| `DATS_GAME_API_URL` | В режиме `api` | Полный move URL, например `https://stadmagic.strangled.net/play/magcarp/player/move` |
| `DATS_SHOW_VISUALIZATION` | Нет | `true` по умолчанию |
| `DATS_PLAY_SOUND` | Нет | `false` по умолчанию |

## 6. Обработка ошибок (Error Handling)

| Случай | Реакция |
|---|---|
| HTTP `401`, `400`, `403` | Диагностическое сообщение без токена и завершение сетевого цикла |
| HTTP `429` | Пауза не менее 1 секунды перед повтором |
| HTTP `5xx` или сетевой сбой | Пауза 5 секунд и повтор |
| Не задан токен/URL в API-режиме | Ошибка до открытия сетевого цикла |

## 8. Тестирование

### Unit-тесты

- Проверить env defaults и fail-fast без token/URL в режиме `api`.
- Проверить начальное тело запроса и заголовок `X-Auth-Token`.
- Проверить обработку `401`, `429`, `5xx`.

### E2E-тесты

- Запустить против локальной арены зарегистрированным тестовым токеном; убедиться, что первый запрос получает snapshot, а следующие содержат действия.
