# FE-001: Конфигурация и запуск Node.js-игрока

## 1. Контекст и бизнес-цель

Убрать привязку клиента к `token.txt` и `localhost`, добавить штатный запуск активного `actioner/index.ts`, не изменяя его игровую стратегию.

## 2. Архитектурное решение

- `src/api/token.ts` экспортирует конфигурацию из обязательных `DATS_PLAYER_TOKEN` и `DATS_GAME_API_URL`.
- URL является полным move endpoint; API-клиенты не конструируют несколько разных адресов.
- `getMap` и `move` устанавливают `Content-Type: application/json` и `X-Auth-Token`.
- Успешным считается только 2xx response. На 429 клиент повторяет тот же запрос после `Retry-After` (если заголовок отсутствует — через 1 секунду); другие HTTP-ошибки и сетевые ошибки завершают actioner с сообщением.
- `package.json` предоставляет runtime-зависимость `tsx` и script `start:actioner`; launcher script ставит зависимости по lockfile только если их ещё нет.
- Игровой actioner оставляет прежний внутренний pacing (3 запроса/с); новый транспорт не должен его увеличивать.

## 3. Схема базы данных (Prisma)

Изменений базы данных нет.

## 4. Алгоритмы и вспомогательные функции

Планирование и вычисление transport actions не меняются. Обновляется только конфигурация API и ошибка/повтор на сетевом уровне.

## 5. API-контракты и DTO

Новых endpoint нет. Используется игровой `POST /play/magcarp/player/move` с телом `{ "transports": [...] }`.

| Переменная | Обязательность | Назначение |
|---|---|---|
| `DATS_PLAYER_TOKEN` | Да | Токен команды; HTTP header `X-Auth-Token` |
| `DATS_GAME_API_URL` | Да | Полный URL move endpoint |

## 6. Обработка ошибок

| Случай | Реакция |
|---|---|
| Отсутствующая env config | Fail-fast до первого обращения к API |
| Любой не-2xx, кроме 429 | Терминальная ошибка; actioner печатает статус и тело ответа |
| 429 | Повтор того же тела запроса после `Retry-After` либо паузы в 1 секунду; повторы продолжаются до успешного ответа |
| Network error | Диагностическое сообщение и завершение процесса; автоматический retry не выполняется |

## 8. Тестирование

### Unit-тесты

- Без обязательной env-конфигурации сетевой запрос не отправляется.
