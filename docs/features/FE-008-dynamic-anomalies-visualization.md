# FE-008: Визуализация динамических аномалий, вихревых полей и эффектов разрушения (Dynamic Anomalies Visualizer & Destruction Rendering)

> Техническая спецификация доработки Python 2D-визуализатора (Pygame) для отрисовки перемещающихся аномалий, графического разделения ядра и зоны влияния, различия притягивающих и отталкивающих вихрей, векторов их скорости и индикации гибели ковра игрока.

---

## 1. Контекст и бизнес-цель

Фича расширяет графический клиент телеметрии (`visualizer`), реализованный в рамках [`FE-005`](file:///Users/d.byta/Documents/Code/dats/datsmagic/docs/features/FE-005-python-2d-visualizer.md), обеспечивая наглядное визуальное представление новой динамической механики из [`DR-005`](file:///Users/d.byta/Documents/Code/dats/datsmagic/docs/domain/DR-005-anomalies.md). Оператор или разработчик бота должен четко видеть траекторию движения аномалии, ее смертоносное ядро, тип силового поля (притяжение или отталкивание) и факт уничтожения ковра.

---

## 2. Архитектурное решение

Модуль `visualizer` обновляет сетевой клиент (`visualizer::client`), конвейер сцены (`visualizer::renderer`) и информационный интерфейс (`visualizer::hud`).

### Ключевые изменения:
1. **`client.py`**:
   - `AnomalyState`: добавлены поля `type: str`, `core_radius: float`, `velocity: Vector2D`.
   - Поддержка статуса игрока `"destroyed"`.
2. **`renderer.py`**:
   - Отрисовка смертоносного темного/огненного ядра радиусом $R_{core} \cdot \text{zoom}$.
   - Отрисовка внешней области действия $R_{effect} \cdot \text{zoom}$:
     - Для `attracting`: закручивающиеся внутрь спирали темных песчано-фиолетовых тонов с направлением к ядру.
     - Для `repelling`: расходящиеся наружу ударные волны/концентрические кольца янтарно-оранжевого цвета.
   - Отрисовка вектора скорости движения аномалии $\vec{V}_{anomaly}$.
   - Графический эффект гибели ковра: перечеркнутый маркер и анимация рассеивания обломков/огня.
3. **`hud.py`**:
   - Отображение числа активных вихрей на арене.
   - Отображение аварийного баннера `CARPET DESTROYED` по центру экрана при `player.status == "destroyed"`.

## 3. Модели и структуры данных (Python)

```python
from dataclasses import dataclass

@dataclass(frozen=True)

    anomaly_type: str  # "attracting" | "repelling"
    position: Vector2D
    velocity: Vector2D
    core_radius: float
    effect_radius: float
    force: float
```

## 4. Алгоритмы отрисовки элементов

### 4.1 Отрисовка смертоносного ядра и зоны влияния аномалии
1. **Экранные координаты центра:** $(sx, sy) = \text{camera.world\_to\_screen}(x, y)$.
2. **Радиус ядра:** $r_{core} = \max(3, \text{int}(R_{core} \cdot \text{zoom}))$.
3. **Радиус влияния:** $r_{effect} = \text{int}(R_{effect} \cdot \text{zoom})$.
4. **Визуализация зоны влияния:**
   - Для `attracting`: отрисовка 4 логарифмических спиралей, вращающихся по часовой стрелке по направлению к центру.
   - Для `repelling`: отрисовка концентрических окружностей с увеличивающимся фазовым сдвигом (эффект пульсирующей ударной волны, исходящей от ядра).
5. **Визуализация ядра:**
   - Залитый круг цвета `(30, 20, 40)` с контрастной пульсирующей границей цвета опасности `(220, 20, 60)`.
   - Внутри ядра отображается пиктограмма черепа или предупреждающий маркер `X`.

### 4.2 Отрисовка вектора скорости аномалии
- От центра $(sx, sy)$ проводится пунктирная или тонкая стрелка вдоль вектора $\vec{V}_{anomaly}$, показывающая траекторию движения аномалии на следующие несколько тиков.

### 4.3 Отрисовка гибели ковра
- При `player.status == "destroyed"`:
  - Ковер не отрисовывается на своем месте.
  - По центру экрана выводится полупрозрачный темный баннер с крупной надписью `CARPET DESTROYED BY ANOMALY CORE` шрифтом цвета глубокого алого огня.

## 5. Обработка ошибок (Error Handling)

| Исключительная ситуация | Реакция визуализатора |
|---|---|
| В ответе API отсутствуют поля `core_radius` или `type` | Безопасный fallback: `core_radius = radius * 0.2`, `type = "attracting"`, `velocity = Vector2D(0, 0)` для обратной совместимости |
| Нулевой или отрицательный радиус | Клампинг к минимальному значению в 1 пиксель |
