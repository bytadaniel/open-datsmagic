# FE-015: Совместимый снимок Desert и пакетные команды транспорта

## 1. Контекст и бизнес-цель

Сделать `./datsmagic` SSOT внешнего API: реализовать его единственный маршрут и точную схему `Desert`, а также перевести на него визуализатор. Маршруты `/api/*` удаляются.

## 2. Архитектурное решение

`POST /play/magcarp/player/move` принимает пакет `transports`; пустой пакет служит опросом визуализатора. Он возвращает JSON строго типа `Desert` из `datsmagic/src/api/get-map-types.ts`: в том числе `bounties`, а не внутреннее имя монет. Ошибки отдельных команд собираются в `errors[]`; лимит запроса сохраняет `429`.

Числовые значения мира берутся из `map.json`: карта `9000×9000`, `maxSpeed=110`, `maxAccel=40`, параметры атаки и щита, радиус транспорта, а также исходные квоты 45 аномалий и 368 bounties. Текущая конфигурация переопределяет квоту аномалий до 15 (для снижения плотности) и bounties до 2000 (FE-017); API-контракт при этом не меняется.

## 3. Алгоритмы и модели

`TransportDto` получает `velocity`, `selfAcceleration`, `anomalyAcceleration`, health/status/cooldowns. `AnomalyDto` получает `radius`, `effectiveRadius`, `strength`. `TreasureState` преобразуется в `BountyDto`.

## 4. План реализации

- [x] Описать точные DTO `Desert`, маршрутизацию и миграцию визуализатора.
- [x] Добавить адаптеры состояния и ошибок пакета.
- [x] Добавить контрактные тесты на основе сокращенного образца `map.json`.

## 5. Критерии приемки

- [x] Пустой пакет возвращает JSON с точным набором полей `Desert`.
- [x] Команда одного транспорта не отменяет результаты остальных.
- [x] Визуализатор опрашивает только `POST /play/magcarp/player/move`; `/api/*` не зарегистрированы.
