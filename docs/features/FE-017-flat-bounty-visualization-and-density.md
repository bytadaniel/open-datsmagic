# FE-017: Плоские bounties и увеличенная плотность монет

## 1. Контекст и бизнес-цель

Игроку нужен плотный набор собираемых bounties, распределенных по арене и пополняемых после сбора. Контракт и плотность являются серверной ответственностью.

## 2. Архитектурное решение

- Квота мира `bounty_quota` и генератора устанавливается в 1000 монет.
- Координаты каждой монеты выбираются случайно по всей доступной площади арены `[margin, width-margin] × [margin, height-margin]`; при сборе пул пополняется до полной квоты.
- Клиентское представление bounties определено в `visualizer_2/docs/features/FE-002-world-rendering.md`.

## 3. Критерии приемки

- [ ] Новая игра содержит до 1000 монет при включенном спавнере.
- [ ] Монеты появляются по всей площади арены, с безопасным отступом от границ.
- [ ] Номиналы и сбор сокровищ не меняются.
