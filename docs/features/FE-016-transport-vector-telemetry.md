# FE-016: Телеметрия трех векторов транспорта

## 1. Контекст и бизнес-цель

Текущий визуализатор неверно трактует серый `P` как третий вектор. Внешний контракт определяет диагностическую тройку `velocity`, `selfAcceleration`, `anomalyAcceleration`.

## 2. Архитектурное решение

Состояние ковра хранит отдельно собственное эффективное ускорение и результат внешних сил. API передает оба поля. Клиентские правила отображения трех векторов определены отдельно в `docs/components/arena-visualizer/features/FE-002-world-rendering.md`.

## 3. План реализации

- [ ] Добавить `anomaly_acceleration` в состояние и DTO; вычислять его до интегрирования.

## 4. Критерии приемки

- [ ] Их сумма участвует в интегрировании скорости по документированной формуле.
- [ ] Снимок API позволяет клиенту воспроизвести диагностическую тройку.
