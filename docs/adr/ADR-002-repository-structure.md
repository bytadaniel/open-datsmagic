# ADR-002: Первичная структура монорепозитория

## Решение на момент принятия

Код симулятора, визуализатор и документация размещались в отдельных верхнеуровневых папках. Тогда Rust-визуализатор назывался `visualizer_2`, Python-клиент оставался fallback, а документы визуализатора лежали рядом с исходниками.

## Статус

Это историческое решение заменено [ADR-003: компонентная структура монорепозитория](ADR-003-repository-layout.md). Актуальные пути, правила Cargo workspace, расположение спецификаций и судьба Python-визуализатора описаны только в ADR-003 и [`AGENTS.md`](../../AGENTS.md).

## Причина замены

С появлением Hub и независимых вариантов ботов прежняя топология перестала отражать реальные границы продуктов. Локальное хранение документации также противоречило требованию единого `docs/` как SSOT. Python UI был заменён нативным Rust-приложением.
